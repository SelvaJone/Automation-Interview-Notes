# Selenium Windows and Tabs

## 1. What is Window Handling in Selenium?

A web application can open:

* A new browser window
* A new browser tab
* Multiple tabs/windows

Selenium uses **window handles** to identify and switch between them.

The important methods are:

```java
driver.getWindowHandle();
driver.getWindowHandles();
driver.switchTo().window();
```

---

# 2. `getWindowHandle()`

`getWindowHandle()` returns the unique ID of the current browser window or tab.

```java
String parentWindow = driver.getWindowHandle();

System.out.println(parentWindow);
```

Example output:

```text
CDwindow-8F4A12...
```

The actual value is generated by the browser and will be different for every session.

---

# 3. `getWindowHandles()`

`getWindowHandles()` returns the IDs of **all currently open windows/tabs**.

```java
Set<String> windows = driver.getWindowHandles();

System.out.println(windows);
```

Because Selenium returns a `Set<String>`, import:

```java
import java.util.Set;
```

---

# 4. Basic Window Switching

Suppose the application opens a second window.

```java
String parentWindow = driver.getWindowHandle();

Set<String> allWindows = driver.getWindowHandles();

for (String window : allWindows) {

    if (!window.equals(parentWindow)) {

        driver.switchTo().window(window);

        break;
    }
}
```

Now Selenium is controlling the child window.

---

# 5. Complete Example — Parent and Child Window

```java
import java.util.Set;

import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;

public class WindowHandling {

    public static void main(String[] args) {

        WebDriver driver = new ChromeDriver();

        driver.get("https://example.com");

        String parentWindow = driver.getWindowHandle();

        driver.findElement(By.id("openWindow")).click();

        Set<String> allWindows = driver.getWindowHandles();

        for (String window : allWindows) {

            if (!window.equals(parentWindow)) {

                driver.switchTo().window(window);

                System.out.println("Child Window Title: "
                        + driver.getTitle());

                System.out.println("Child Window URL: "
                        + driver.getCurrentUrl());

                break;
            }
        }

        driver.quit();
    }
}
```

---

# 6. Switching Back to Parent Window

After working with the child window:

```java
driver.switchTo().window(parentWindow);
```

Example:

```java
String parentWindow = driver.getWindowHandle();

// Open child window
// Switch to child
// Perform actions

driver.switchTo().window(parentWindow);
```

Now Selenium is controlling the parent window again.

---

# 7. Complete Parent → Child → Parent Flow

The common flow is:

```text
Parent Window
      ↓
Click link/button
      ↓
Child Window Opens
      ↓
Get all window handles
      ↓
Switch to Child
      ↓
Perform actions
      ↓
Close Child
      ↓
Switch back to Parent
```

Code:

```java
String parentWindow = driver.getWindowHandle();

driver.findElement(By.id("openWindow")).click();

Set<String> windows = driver.getWindowHandles();

for (String window : windows) {

    if (!window.equals(parentWindow)) {

        driver.switchTo().window(window);

        // Perform child-window actions

        driver.close();

        break;
    }
}

driver.switchTo().window(parentWindow);
```

---

# 8. `driver.close()` vs `driver.quit()`

This is an important interview question.

## `close()`

Closes the **currently active browser window/tab**.

```java
driver.close();
```

Example:

```text
Parent + Child

driver.close()

Result:

Parent remains open
Child closes
```

---

## `quit()`

Closes the **entire browser session**, including all windows/tabs.

```java
driver.quit();
```

Example:

```text
Parent + Child + Tab 3

driver.quit()

Result:

Everything closes
```

### Easy way to remember

```text
close() → current window
quit()  → entire browser session
```

---

# 9. Handling Multiple Windows

Suppose we have:

```text
Window 1
Window 2
Window 3
Window 4
```

We can get all handles:

```java
Set<String> windows = driver.getWindowHandles();
```

Then loop through them:

```java
for (String window : windows) {

    driver.switchTo().window(window);

    System.out.println("Title: " + driver.getTitle());
    System.out.println("URL: " + driver.getCurrentUrl());
}
```

This visits every window.

---

# 10. Using an Iterator

Another way to work with window handles is `Iterator`.

```java
Set<String> windows = driver.getWindowHandles();

Iterator<String> iterator = windows.iterator();

String parentWindow = iterator.next();

String childWindow = iterator.next();

driver.switchTo().window(childWindow);
```

Required imports:

```java
import java.util.Iterator;
import java.util.Set;
```

However, be careful with this approach when there are more than two windows because the order should not be relied upon for identifying a specific business window.

---

# 11. Better Approach — Compare Handles

A safer approach is:

```java
String parentWindow = driver.getWindowHandle();

Set<String> windows = driver.getWindowHandles();

for (String window : windows) {

    if (!window.equals(parentWindow)) {

        driver.switchTo().window(window);

        break;
    }
}
```

This explicitly identifies the window that isn't the parent.

---

# 12. Switching to a Specific Window by Title

Sometimes we don't know the window handle we need, but we know the title.

```java
Set<String> windows = driver.getWindowHandles();

for (String window : windows) {

    driver.switchTo().window(window);

    if (driver.getTitle().equals("Expected Title")) {

        break;
    }
}
```

Now Selenium is controlling the window with that title.

---

# 13. Switching to a Window by URL

We can also identify a window based on its URL.

```java
Set<String> windows = driver.getWindowHandles();

for (String window : windows) {

    driver.switchTo().window(window);

    if (driver.getCurrentUrl().contains("checkout")) {

        break;
    }
}
```

This can be useful when multiple windows are open.

---

# 14. Store Parent and Child Handles

A common framework pattern is:

```java
String parentWindow = driver.getWindowHandle();

Set<String> windows = driver.getWindowHandles();

String childWindow = null;

for (String window : windows) {

    if (!window.equals(parentWindow)) {

        childWindow = window;
        break;
    }
}

driver.switchTo().window(childWindow);
```

Then:

```java
driver.switchTo().window(parentWindow);
```

---

# 15. New Tab vs New Window

From Selenium's perspective, both are controlled using window handles.

For example:

```java
Set<String> handles = driver.getWindowHandles();
```

Whether the browser opened a:

* Tab
* Separate window

you generally use:

```java
driver.switchTo().window(handle);
```

to switch to it.

---

# 16. Selenium 4 — Open a New Tab

Selenium 4 provides a convenient API for creating a new tab.

```java
driver.switchTo().newWindow(WindowType.TAB);
```

Example:

```java
driver.get("https://www.google.com");

driver.switchTo().newWindow(WindowType.TAB);

driver.get("https://www.amazon.com");
```

Required import:

```java
import org.openqa.selenium.WindowType;
```

---

# 17. Selenium 4 — Open a New Window

Selenium 4 can also create a new browser window:

```java
driver.switchTo().newWindow(WindowType.WINDOW);
```

Example:

```java
driver.get("https://www.google.com");

driver.switchTo().newWindow(WindowType.WINDOW);

driver.get("https://www.amazon.com");
```

# 18. New Tab Example

```java
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import org.openqa.selenium.WindowType;

public class NewTabExample {

    public static void main(String[] args) {

        WebDriver driver = new ChromeDriver();

        driver.get("https://www.google.com");

        String parentWindow = driver.getWindowHandle();

        driver.switchTo().newWindow(WindowType.TAB);

        driver.get("https://www.example.com");

        System.out.println("Child URL: "
                + driver.getCurrentUrl());

        driver.close();

        driver.switchTo().window(parentWindow);

        System.out.println("Parent URL: "
                + driver.getCurrentUrl());

        driver.quit();
    }
}
```

---

# 19. Important Concept — Selenium Must Switch

A common beginner mistake is assuming Selenium automatically controls the newly opened tab.

It does not.

Suppose:

```java
driver.findElement(By.id("open")).click();
```

opens a new tab.

Selenium may still be controlling the original window.

You need:

```java
driver.switchTo().window(childWindow);
```

before interacting with elements in the child.

---

# 20. Common Error

You may see:

```text
NoSuchElementException
```

when trying to find an element that exists in another window.

For example:

```java
driver.findElement(By.id("childElement")).click();
```

If the element is in the child window, Selenium cannot find it while it is still controlling the parent.

Correct:

```java
driver.switchTo().window(childWindow);

driver.findElement(By.id("childElement")).click();
```

# 21. Utility Method for Switching to Child Window

We can create a reusable method:

```java
public static void switchToChildWindow(
        WebDriver driver,
        String parentWindow) {

    Set<String> windows = driver.getWindowHandles();

    for (String window : windows) {

        if (!window.equals(parentWindow)) {

            driver.switchTo().window(window);

            break;
        }
    }
}
```

Usage:

```java
String parentWindow = driver.getWindowHandle();

driver.findElement(By.id("openWindow")).click();

switchToChildWindow(driver, parentWindow);
```

---

# 22. Utility Method for Switching by Title

```java
public static void switchToWindowByTitle(
        WebDriver driver,
        String expectedTitle) {

    Set<String> windows = driver.getWindowHandles();

    for (String window : windows) {

        driver.switchTo().window(window);

        if (driver.getTitle().equals(expectedTitle)) {

            return;
        }
    }
}
```

Usage:

```java
switchToWindowByTitle(
        driver,
        "Checkout - Example"
);
```

# 24. Interview Questions

## Q1. How do you handle multiple windows in Selenium?

### Answer

> I use `getWindowHandle()` to capture the current window ID and `getWindowHandles()` to get all open window IDs. Then I use `switchTo().window()` to switch between windows.

---

## Q2. What is a window handle?

### Answer

> A window handle is a unique identifier assigned by Selenium to a browser window or tab.

Example:

```java
String handle = driver.getWindowHandle();
```

---

## Q3. Difference between `getWindowHandle()` and `getWindowHandles()`?

| Method               | Purpose                         |
| -------------------- | ------------------------------- |
| `getWindowHandle()`  | Returns current window handle   |
| `getWindowHandles()` | Returns all open window handles |

---

## Q4. How do you switch to a child window?

```java
String parent = driver.getWindowHandle();

Set<String> windows = driver.getWindowHandles();

for (String window : windows) {

    if (!window.equals(parent)) {

        driver.switchTo().window(window);
        break;
    }
}
```

---

## Q5. How do you switch back to the parent?

```java
driver.switchTo().window(parent);
```

---

## Q6. What is the difference between `close()` and `quit()`?

> `close()` closes the currently active window or tab, while `quit()` closes the entire browser session and all associated windows.

---

## Q7. Can Selenium handle multiple tabs?

Yes.

Selenium treats browser tabs and windows using window handles.

```java
driver.switchTo().window(handle);
```

# 25. Selenium vs Playwright — Windows/Tabs

This is an important SDET interview comparison.

### Selenium

Selenium commonly uses:

```java
String parent = driver.getWindowHandle();

Set<String> windows = driver.getWindowHandles();

for (String window : windows) {

    if (!window.equals(parent)) {

        driver.switchTo().window(window);

        break;
    }
}
```

You explicitly obtain the handles and switch to the required window.

---

### Playwright

Playwright can listen for a new page:

```javascript
const newPagePromise =
    page.context().waitForEvent('page');

await page.getByRole('link', {
    name: 'Open New Tab'
}).click();

const newPage = await newPagePromise;
```

Then:

```javascript
await newPage.getByRole('button', {
    name: 'Continue'
}).click();
```

---

# 26. Selenium vs Playwright Quick Comparison

| Operation           | Selenium                       | Playwright                                       |
| ------------------- | ------------------------------ | ------------------------------------------------ |
| Current window      | `getWindowHandle()`            | `page`                                           |
| All windows         | `getWindowHandles()`           | `context.pages()`                                |
| Switch window       | `switchTo().window()`          | Use `Page` object                                |
| New tab             | `newWindow(WindowType.TAB)`    | `context.newPage()`                              |
| New window          | `newWindow(WindowType.WINDOW)` | Browser context/page handling                    |
| New popup/tab event | Window handles                 | `waitForEvent('page')` / `waitForEvent('popup')` |
| Close current       | `driver.close()`               | `page.close()`                                   |
| Close browser       | `driver.quit()`                | `browser.close()`                                |
